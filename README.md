# 💧 Controlador de Nível de Reservatório de Água

## 📌 Sobre o projeto

Este projeto foi desenvolvido em Python com o objetivo de apresentar diferentes níveis de um reservatório de água, exibindo cada situação com uma cor correspondente no terminal.

O programa utiliza uma lista para armazenar os níveis do reservatório, uma função para definir as cores dos alertas e uma estrutura de repetição para exibir todas as situações. 

O projeto foi desenvolvido para fins educacionais, como parte da minha jornada de aprendizado em Desenvolvimento de Sistemas e Python.

## 🎯 Objetivos

* Desenvolver a lógica de um sistema de classificação de níveis.
* Praticar a criação e utilização de listas em Python.
* Desenvolver funções para organização do código.
* Utilizar estruturas condicionais (if, elif e else).
* Aplicar estruturas de repetição (for).
* Utilizar a biblioteca Colorama para exibir textos coloridos no terminal.

## 🚀 Melhorias futuras

* Permitir que o usuário informe o nível atual do reservatório.
* Validar os dados informados.
* Exibir somente o alerta correspondente ao nível selecionado.
